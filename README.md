## Описание проекта

### Сущности
1. **Книга** — название, год выпуска, описание, ISBN, фото главной страницы.
2. **Авторы** — ФИО.

### Права доступа
* **Гость** — только просмотр + подписка на новые книги автора. 
* **Юзер** — просмотр, добавление, редактирование, удаление.

### Отчетность
* **ТОП-10 авторов** — список авторов, выпустивших больше всего книг за определенный год (доступен всем пользователям).

---

## 🛠 Технологический стек

*   **Backend:** PHP 8.4 (FPM), Symfony 8.1
*   **Database:** PostgreSQL 17
*   **Database ORM:** Doctrine ORM 3.x & Migrations
*   **Frontend/Assets:** Symfony AssetMapper, Twig, Bootstrap 5.3, Stimulus, Turbo (Hotwire)
*   **Queue/Async:** Symfony Messenger (Doctrine Transport)
*   **Mail Testing:** Mailpit (Mailer)
*   **Dev Tools & Testing:** PHPUnit, Zenstruck Foundry (фабрики фикстур), MakerBundle

---

## ✨ Основной функционал

1.  **Каталог книг и авторов:** Просмотр списков с поддержкой постраничной навигации (пагинации).
2.  **Управление данными (CRUD):** Авторизованные пользователи могут добавлять, редактировать и удалять книги и авторов.
3.  **Асинхронные уведомления:** При добавлении новой книги срабатывает событие (`BookCreatedEvent`), которое через `Symfony Messenger` отправляет подписчикам автора email-уведомления в фоновом режиме порциями (пачками).
4.  **Подписка на авторов:** Любой посетитель может оставить свой Email на странице автора, чтобы получать уведомления.
5.  **Рейтинги и отчеты:** Страница со статистикой топ-10 авторов по количеству выпущенных книг за выбранный год.
6.  **Тестирование почты:** Все исходящие фоновые письма перехватываются локальным сервером Mailpit.

## 🚀 Быстрый запуск в Docker

Для удобства управления локальным окружением в проекте настроен `Makefile`.

### 1. Подготовка окружения
Создайте локальный файл конфигурации из шаблона:
```bash
cp .env.example .env
```

### 2. Инициализация и запуск проекта
Выполните одну команду для полной сборки и подготовки проекта (сборка контейнеров, установка зависимостей Composer, компиляция ассетов):
```bash
make init
```

### 3. Запуск контейнеров в фоне
Если проект уже инициализирован, для обычного запуска используйте:
```bash
make up
```

### 4. Накатывание миграций и фикстур
Создайте структуру таблиц в базе данных и наполните её демонстрационными данными (20 авторов, 20 книг, 50 подписчиков и администратор):
```bash
make migrate-up
make fixture-load
```

### 5. Запуск обработчика очереди (важно)
Чтобы асинхронные задачи (отправка писем подписчикам при создании книги) выполнялись, запустите воркер Messenger в отдельном терминале:
```bash
make queue-work
```

## 📋 Список команд Makefile

В проекте доступны следующие команды для автоматизации разработки:

*   `make build` — Сборка Docker-образов.
*   `make up` — Запуск контейнеров в фоновом режиме.
*   `make down` — Остановка контейнеров.
*   `make clear` — Остановка контейнеров с удалением связанных volumes (очистка БД).
*   `make shell` — Подключение к CLI-сессии внутри контейнера `app-php` от текущего системного пользователя.
*   `make composer-install` — Установка зависимостей через Composer внутри контейнера.
*   `make cache-clear` — Очистка кэша Symfony приложения.
*   `make migrate-up` — Выполнение всех незапущенных миграций БД.
*   `make migrate-down` — Откат последней миграции.
*   `make fixture-load` — Сброс и заполнение БД тестовыми фикстурами.
*   `make queue-work` — Запуск воркера для обработки очереди сообщений (`async`).

## 📂 Структура ключевых компонентов

*   `src/Controller/` — Контроллеры для управления книгами, авторами, отчетами и авторизацией.
*   `src/Entity/` — Сущности Doctrine ORM (`Book`, `Author`, `Subscriber`, `User`).
*   `src/Event/` & `src/EventSubscriber/` — Логика событий. `BookCreatedSubscriber` перехватывает момент создания книги и отправляет задачу в очередь.
*   `src/Message/` & `src/MessageHandler/` — Компоненты шины сообщений (`NotifySubscribersHandler`). Реализуют пагинационную (batch) рассылку писем, чтобы не перегружать память сервера при миллионах подписчиков.
*   `src/Service/` — Сервисный слой, содержащий бизнес-логику (`BookService`, `AuthorService`, `FileUploader`).
*   `templates/` — Шаблоны отображения Twig, стилизованные с помощью Bootstrap 5.
*   `docker/` — Конфигурационные файлы Nginx и Dockerfile для PHP-FPM (включающий все необходимые расширения: `pdo_pgsql`, `gd`, `intl`, `zip` и др.).
